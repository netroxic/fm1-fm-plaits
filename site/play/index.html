        01 · 三分钟上手

        网页顶部和实机 HOME 页显示当前版本。开机动画约 1 秒，按键或旋钮可跳过；开机不会自动播放。

        FM1 有 8 条轨道、6 种音源、16 个内置工程。每轨支持 16、32、48 或 64 步；常用操作使用单键，完整细调放在长按菜单和网页里。

        1. 准备试听。实机把 MASTER 放在适中的位置；网页点琴键或播放即可发声，无需额外开关。
        2. 先听一个预设。在 HOME 总览直接转 PRESETS 切换整套预设，按 PLAY 播放。也可按 HOME 打开列表，转 PRESETS／SELECT 直接载入，PLAY 载入播放。SAVE 打开项目保存，白键 1–16 也能直接选对应预设。
        3. 改声音。回总览后 SELECT 选轨，短按 EDIT 进入常用参数；在 EDIT 页转 PRESETS 换当前轨音色，再按 EDIT 返回。想换音源，在总览转 ALGORITHM 或 K2，SAVE 应用。
        4. 改节奏。按 SEQ，基础页 K3 选音符或鼓声部，白键开关步；PRESETS 选步，OCT−／OCT+ 翻页。ALGORITHM 翻底部参数页，细节和节奏直接可调。
        5. 调平衡。按 GLO 进入混音，白键 1–8 静音、9–16 独奏；SELECT 选轨，K1–K4 调四轨音量。再按 GLO 或 HOME 返回。
        6. 保存。按 SAVE，SELECT 选 USER 槽，再按 SAVE 保存；覆盖其他已有槽会提示确认，成功后自动返回。

        网页顶部“保存到设备”可直接选槽保存；“存到此浏览器”只存本机浏览器；“导出项目文件”生成电脑备份。实机 SAVE 保存到设备槽。

        02 · 面板与快捷键

        操作用途
        HOME从编辑页回八轨总览；已经在总览时打开预设，再按取消。
        SELECT总览、常用音色、步进和混音页选轨；完整细调页翻参数页；菜单选项目。
        PRESETS总览直接切换整套工程预设；EDIT 页选当前轨音色；预设列表选工程；SEQ 选步；808／采样编辑页选声部；SAVE 页选存档槽。
        ALGORITHM总览选择合成引擎，SAVE 应用、HOME 取消；SEQ／ARP 翻底部参数页；音色编辑页调算法或音色参数。
        K1 / K2 / K3 / K4总览：音量／音源／步位置／速度。SEQ 基础页：音量／步位置／音高或鼓声部／速度。其他页看屏幕底部标签。
        EDIT 短按／长按短按进入或退出常用参数；长按约 0.6 秒进入完整细调。非 FM 音源的常用页只显示第一组参数，细调页用 SELECT 翻页。
        SEQ 短按／长按短按进入步进，再按回 BASIC 并恢复播放跟随。ALGORITHM 翻参数页；长按约 0.6 秒打开复制／粘贴、清空、重复、撤销及其他操作。
        GLO单按进入／退出混音。白键 1–8 静音、9–16 独奏，无需一直按住 GLO。
        PLAY / REC播放／暂停／续播；音乐页开关音符录入。预设页的 PLAY 为载入并播放，切换预设不弹确认。
        SAVE打开保存页，再按保存；菜单中用于执行／确认。HOME 取消。
        OCT− / OCT+步进页翻 16 步；演奏时上下移调八度。
        ENV / LFO / FX / SCLENV 打开当前音源包络；LFO 打开当前轨调制；FX 按轨调混响和延迟，SCL 进入缩放细调。
        ARP短按开关当前轨琶音／鼓连奏；长按约 0.6 秒打开参数页。SELECT 选轨，ALGORITHM 翻页：分频／方向／音域／门长，Swing／Hold。

        总览转 K3（STEP）选择当前轨的步位置，录入时可移动写入位置。短按 REC 开关录音。

        同一轨的静音与独奏互斥：开启独奏会取消该轨静音，开启静音会取消该轨独奏；其他轨保持原状态。

        网页操作

        选择预设后点“播放”试听。“读取与保存”管理设备读取和浏览器存档，“文件与 MIDI”导入、导出项目和音色。

        常用编辑按钮直接打开音色、步进、混音和效果；其余功能在“更多编辑”。旋钮可拖动或滚轮调节，LCD 数值可点击编辑。电脑键盘 Z、S、X、D…演奏，空格播放，Esc 停音；输入文字和操作菜单时不会演奏。

        上排功能键在所有页面都有效：FX、SCL、ENV、LFO、EDIT、GLO、SEQ 可直接切页，ARP 短按开关、长按调参数，PLAY 控制播放。菜单或步进细节中按 REC，会进入 SEQ 基础页并开始录入；再按结束。SAVE 打开项目保存页，或执行屏幕内的确认；OCT−／OCT+ 在 SEQ 和复制菜单翻步进页，其他页面调八度。离开确认页不会执行待确认操作。

        LCD 数值直接编辑

        把鼠标放在 LCD 上的数值，出现高亮即可滚轮调节；每次按参数最小步长变化，不随滚动速度加速。也可点击打开大号数值框，用滚轮、＋／−或方向键细调，Esc 关闭。支持底部参数、顶部 BPM、总览各轨音量、SEQ 循环长度、步进详情的选步数字、音色参数行、效果参数行，以及 FM 的 ALG、FB、MONO／POLY、ADSR 开关、LFO 波形／同步／PM SENS。混音页也可点静音／独奏格子设置。状态、电平、固定量化和当前引擎不支持的参数只显示；外部 MIDI 时钟下 BPM 由外部控制。切换轨道或参数页会关闭旧编辑框，避免改错参数。总览调其他轨的小音量数字不会改变当前选轨。

        GLO 短按（小于 0.6 秒）进入或退出混音；按住 0.6 秒可临时查看混音，松开回原页。GLO、EDIT、SEQ、ARP 的长按过程中，屏幕顶部显示进度条。

        组合键

        HOME＋PLAY 紧急停音回起点；HOME＋SAVE 撤销／重做；SEQ＋EDIT 打开更多菜单；EDIT＋REC 改 DX7 音色名。都可以从长按 SEQ 的菜单完成对应操作。网页需要锁住按键时可 Shift 点击或右击，再点释放；日常操作无需使用。

        03 · 步进与录入

        16 个白键，一页 16 步

        SEQ 基础页白键开关当前页的步；K3 选音高或鼓声部。PRESETS 在各参数页统一选步，SELECT 选轨，OCT−／OCT+ 每次换 16 步。ALGORITHM 翻底部八页：BASIC、STEP DETAILS、RHYTHM/REC、LOCKS、SYNC / LOOP、MIDI TRACK、MIDI ROUTING、TRACK ROLE。RHYTHM/REC 的 K4 选本轨 16／32／48／64 步，各轨独立循环。

        播放中修改长度会显示 NEXT，到本轨下一轮起点生效。缩短不会删除后面的音符，再加长即可恢复。屏幕 FOLLOW 表示跟随播放翻页；手动编辑后显示 EDIT 并固定页面，再按 SEQ 返回基础页并恢复跟随。

        SEQ 基础页：旋律轨 K2 选步，K3 改已有音符；空步只设待输入音高，按白键写入。鼓轨 K3 选声部，不移动鼓点。K1 调轨道音量，K4 调速度；外部 MIDI 时钟下速度由外部设备控制。

        SEQ 的 SYNC / LOOP 页：K1 选 INT／MIDI，K2 调内部 BPM，K3 调循环长度。切换时钟会停止播放；MIDI 模式需外部 Start／Continue 和 Clock，等待时屏幕提示 WAIT MIDI CLOCK。外部 BPM 只读，蓝牙页的时钟设置仍可使用。

        SEQ 的 MIDI TRACK 页：K1 选 SEQ／ARP 的 LOCAL／BOTH／MIDI 输出，K2 选输出通道，K3 选端口，K4 开关 KEY OUT。MIDI ROUTING 页：K1 为 LOCAL，K2 为 CLK OUT，K3 选 THRU IN，K4 选 THRU OUT。SYNC 页 K4 选时钟来源。这些偏好独立于工程；网页仅预览，不向实际 MIDI 端口外发，实机请通过机身设置。

        录入标记：停止时按 REC 显示 STEP，弹琴逐步写入；播放时显示 REC，按时间录入；启用预备拍后显示 CNT 4→1，下一小节才开始记录。绿色短线表示播放步，白色框表示编辑步；PRESETS 手动选步会结束录入，再按 REC 继续。

        琶音：速度、方向、Swing 与 Hold

        短按 ARP 开启后按住音符；长按 ARP 打开参数。ALGORITHM 翻两页：第一页 K1 为 1/4、1/8、1/16、1/32 分频，K2 方向，K3 为 1–4 个八度，K4 为 25%–100% 门长；第二页 K1 为 0%–50% Swing，K2 开关 Hold。Hold 保持松手后的和弦，全部松手后弹新和弦即可替换；关闭 Hold、停止或紧急停音会释放锁住的音符。SELECT 选轨，各轨参数独立。HOME／SEQ 基础页 K4 调 BPM；外部时钟需 Start／Continue 和 Clock，Swing 按 24 PPQN 的精度变化。

        808／SAMPLER 支持分频、方向、Swing 和 Hold；音域与门长显示“--”，不移调鼓声部。ARP 开关与六项参数随项目保存，按住或 Hold 锁住的音符不保存。

        TRACK ROLE（8/8）：K1 选 NORMAL、PLAY 或 OFF，K2 设输入通道。NORMAL 参与音序与录入；PLAY 用于现场演奏，切换工程时保留本轨音色和持续按住的音符；OFF 关闭本轨发声。角色和输入通道独立于工程保存。MUTE／SOLO 沿用原有操作，NORMAL 与 PLAY 各自判断独奏。

        两种录入方式

        以下录入仅适用于 NORMAL 轨；PLAY 轨用于现场演奏，不参与录入。

        • 停止时按 REC：旋律音符、DRUM 808 和 SAMPLER 都在全部按键松开后前进一步；重叠按下的声音录入同一步。
        • 播放时按 REC：面板或 MIDI 演奏按最近的十六分音符量化写入，并保留力度。再次按 REC 结束录入。

        细节、节奏与复制

        长按 SEQ 约 0.6 秒打开更多菜单。SELECT 选 COPY STEP 或 COPY PAGE，按 SAVE 复制；菜单自动选中对应 PASTE。用 PRESETS 或 K2 选目标步，OCT−／OCT+ 换目标页，再按一次 SAVE 粘贴。顶部显示当前轨、步、页及剪贴板类型；整轨粘贴、清空与重复仍需第二次 SAVE 确认。

        在 SEQ 转 ALGORITHM 到 STEP DETAILS，K1–K4 调力度、门长、概率、和弦；LOCKS 页调连音、参数锁及音符。PRESETS 或白键只选择要编辑的步，SELECT 仍选轨。进入细节或锁参数页会结束 REC 并保留录入，播放不会拉走手动光标。参数锁只作用于一步，下一步恢复；不相关的 MIDI 控制消息不会取消它，支持的 CC 若控制同一参数则覆盖锁定并更新保存值。全项目共享 16 组和弦和 16 个单步参数锁。

        SEQ 的 RHYTHM/REC 页：K1 Swing、K2 节拍器（关闭／录音／常开）、K3 一小节预备拍、K4 循环长度。量化固定为十六分音符。长按 SEQ 仍保留复制、粘贴和更多操作；UNDO / REDO 在当前内容与上次编辑前状态之间切换；音色与音量到达边界后继续拧不会覆盖撤销记录。

        04 · 六种音源

        每条轨道都能选择任意一种音源，同类型的多条轨道也各有参数。切换音源后使用新类型的默认参数；鼓与旋律互换会清空不兼容步进，可从长按 SEQ 的菜单选择 UNDO / REDO 撤销。

        音源怎样编辑
        DX7 · FMEDIT 短按开算法／反馈／移调／音量常用页，再短按返回；长按进入完整编辑。黑键选择 OP1–OP6、Pitch、Global 或 Mono／Poly，SELECT 翻页；长按 OP 黑键约半秒开关算子。ALGORITHM 调算法，PRESETS 选内置音色。
        303 · 酸性贝斯短按 EDIT 调第一页；长按 EDIT 后 SELECT 翻三页：Cutoff／Reso／EnvMod／Decay；Accent／Wave／Tune／Volume；Drive／DrvTyp／Slide／AccDec。PRESETS 切换锯齿／方波，编辑页 Mono／Poly 选择单音滑音或 4 复音。
        808 · 合成鼓PRESETS 选择 11 个鼓声部或 KIT，键盘试听也会选中对应声部。长按 EDIT 后 SELECT 翻参数页。各声部可调参数不同；KIT 调整整套鼓组。
        PSG · 芯片音色K1–K4：MODE（YM／AY／NOISE／MIX）、NOISE、TUNE、RELEASE。纯方波模式下 NOISE 不改变声音。
        PLUCK · 拨弦K1–K4：DECAY、BRIGHT、TUNE、RELEASE。DECAY 是自然衰减，RELEASE 是松键衰减；按住键仍会自然衰减。亮度在下一次拨弦生效。
        SAMPLER · 采样前 8 个白键选择并试听 8 槽采样，PRESETS 也可选择。第一页 Level／Tune／Length／Choke；长按 EDIT 后 SELECT 翻到第二页 Variation／Vel LPF。Choke 同组新击打会停止旧声，适合开闭镲。

        各音源包络与 LFO

        ENV 在所有引擎上可用，显示该音源实际支持的参数。SELECT 选轨；鼓与采样可用 PRESETS 或白键选择声部。重新触发音符试听包络变化，空白旋钮表示该音源没有对应参数。

        FM：K1 Attack、K2 Decay、K3 Sustain、K4 Release，调整即启用。303：K1 EnvMod、K2 Decay、K3 AccDec、K4 Cutoff；力度 100 及以上使用重音衰减 AccDec。PSG：K1 Release。Pluck：K1 Decay、K2 Release、K3 Bright。Sampler：K1 Length、K2 Choke。808：K1 Decay、K2 Attack、K3 Tone、K4 Tune，只显示所选鼓声部支持的项目。

        非 FM 引擎按 LFO：K1 速度 0.05–20 Hz，K2 深度 0–100%，K3 音量起伏／左右声像，K4 三角波／方波／上升锯齿／下降锯齿。深度 0 即关闭；参数随项目、轨道音色及用户槽保存。SELECT 选轨，再按 LFO 返回。

        LFO 作用于整个轨道，包括全部鼓／采样声部，也影响轨道效果发送。当前非 FM LFO 不提供音高或滤波目标。FM 保留原有音高／振幅 LFO 和两页参数。效果使用 FX。

        FM 包络、调制与命名

        EDIT 的 OP RATES／OP LEVELS 显示同一条包络：RATE 越大，对应阶段越短；LEVEL 改变折点高度。L3 保持到松键，随后按 R4 到达 L4。六个算子和 PITCH 包络均会随参数更新。图形为便于编辑的示意，不是毫秒刻度；实际时长还取决于音符、缩放与电平。

        FM ENV 的 A、D、S、R 都会实时改变曲线；横向按实际包络时间比例绘制，保持段只作示意，持续到松键。ADSR 关闭时曲线变灰并标为预览，实际声音使用各算子的 DX7 包络。

        ENV 打开总 ADSR 页，K1–K4 为 Attack／Decay／Sustain／Release；转动任一参数会自动启用，重新弹键试听。只浏览页面保留原音色；需要回到原 DX7 包络时，PRESETS 向左关闭覆盖层，向右重新启用。LFO 用 SELECT 翻两页，SCL 进入当前算子的键盘缩放。长按 SEQ，选择 DX7 PATCH NAME 并按 SAVE，编辑 10 字符音色名，SELECT 选字符，K1 改字符，保存项目后保留。

        多数调音和包络参数需重新触发音符试听。切换 DX7 内置音色会替换编辑、打开全部算子并关闭总 ADSR。

        轨道效果

        按 FX，SELECT 选轨；K1 混响发送、K2 延迟发送，0 即关闭该轨发送，六种音源均可用。K3 轨道音量、K4 共用效果返回量。转 PRESETS 到第二页细调：K1 混响时间、K2 延迟时间、K3 反馈、K4 返回量，由所有轨道共用。808 在 EDIT 中仍可设置每个鼓声部的额外发送量。轨道发送量随项目和轨道音色保存；共用效果参数仅随项目保存。静音停止新发送，已有尾音自然衰减。

        05 · 音量与混音

        MASTER 是总输出音量。实机旋钮控制合成器、USB 与蓝牙输入的最终输出，也影响 USB 录音。最小位置静音，切换项目沿用旋钮位置；它不随项目保存。转动时屏幕短暂显示 MASTER 百分比或 MASTER MUTED。

        轨道 LEVEL 是项目里的混音音量。在 HOME／SEQ 基础页用 K1 调当前轨。303 的 Volume、808 的声部 Level 和采样 Level 用于音色内部的平衡。

        1. 按一下 GLO 进入混音，按白键 1–8 切换对应轨静音。
        2. 按一下 GLO 进入混音，按白键 9–16 切换对应轨独奏。
        3. 混音页中，SELECT 选轨；K1–K4 调当前四轨组（1–4 或 5–8）的音量。

        多个轨道可以同时独奏；同一轨的静音与独奏互斥。

        网页“静音”只关闭试听，编辑与音序仍继续。要停回起点，请用 HOME＋PLAY 或“紧急停音”。

        06 · 保存与文件

        工作区 ≠ 已保存项目。实机未保存的编辑只在内存中，重新开机或载入其他项目会丢失。网页与实机各有自己的存档；“保存到设备”会完成传输、写入槽位和读回校验。

        预设与保存分开操作

        直接切换：在 HOME 总览转 PRESETS 即可切整套预设，屏幕显示当前工程名称；播放中切换会继续播放，停止时切换保持停止。切换直接生效，不提示保存。单轨音色在 EDIT 页用 PRESETS 选择。

        浏览列表：总览按 HOME 打开预设，K1 向右选 FACTORY（16 个内置工程）、向左选 USER（16 个用户槽）。PRESETS／SELECT 直接载入对应编号，PLAY 载入并播放，SAVE 打开项目保存；白键 1–16 直接选编号并沿用之前的播放状态。空 USER 槽会提示，不替换当前项目。

        切换预设会直接替换当前工作区，包括未保存的修改；想保留修改时，先按 SAVE 保存。官方工程只读，编辑后请存入 USER。

        保存：SAVE 打开保存页，SELECT／PRESETS 选 USER 槽，K1 选名称字符、K2 改字符；再按 SAVE 写入。覆盖其他已有槽须再按 SAVE 确认，成功后自动回原页面，HOME 取消。当前槽直接更新。标题星号表示未保存。

        顶部状态区区分浏览器试听、设备连接和未写入的网页修改。连接不会自动读取或同步；点常用区“读取设备项目”替换网页工作区，误操作可用 HOME＋SAVE 撤销。保存并读回校验一致后才显示已写入；仅存到浏览器不代表写入设备。实机旋钮修改后，请重新读取。

        项目保存各轨 ARP 开关与参数；采样音频须另备份采样库。

        NORMAL 轨的音色修改随项目保存；PLAY 轨的音色修改请导出轨道音色，DX7 也可存入独立库。项目备份不包含独立音色库和采样音频。

        把网页作品放入 FM1

        1. 用 USB 数据线连接 FM1；在网页完成编辑，点顶部“保存到设备”。
        2. 允许浏览器 MIDI／SysEx，选择目标槽位，点击“保存并校验”。已有槽位内容会被替换。
        3. 看到“读回校验通过”再断开设备。重启后可在 USER 列表载入对应槽；不需要另外按实机 SAVE。

        “读取设备项目”把当前实机工作区带入仿真；“恢复到工作区”也不会自动覆盖设备槽。网页的 SAVE 写入浏览器本地槽，清理浏览器数据会删除这些存档，重要作品请导出。

        文件包含什么
        .fm1完整八轨项目：音源、参数、轨道音量、循环长度、步进等；不含采样音频。
        .fm1t一条轨道的音源类型、音色参数和音量；不携带步进。支持全部六种音源。
        .syxDX7 标准音色，支持单音色和 32 音色库。设备目标轨须设为 DX7。
        .fm1s完整 8 槽采样库，所有项目共用。使用自定义采样的作品须另备份此文件。

        项目库列表读取失败时，载入、保存和导入按钮保持禁用；点击“刷新列表”重试。只有完整读取成功后才开放操作，重试会保留有效的选中槽位。

        07 · 采样库

        在“项目与音色”的“8 槽采样库”编辑音频。8 槽共用 436 KiB，约 19.55 秒；可自由分配，页面显示剩余容量。先读取设备库，可保留已有采样。

        WAV：PCM 8/16/24/32 位或 32 位浮点，单声道或立体声，8–192 kHz；原文件不超过 32 MiB、120 秒。8 槽共享约 19.55 秒，可自由分配；每段按 10 毫秒向上取整，替换时可复用当前槽空间。

        1. 先选完整库。修改现有实机采样时先连接项目库并“读取设备采样库”，再“备份网页采样库”。也可从内置库或 .fm1s 文件开始。
        2. 选择采样槽与 WAV。设置名称（最多 15 个英文字符）、起点和终点，用“试听选段”检查裁切。
        3. 可选：先在网页编辑。点击“编码并替换网页槽位”可先编辑网页库；直接写入设备时会自动完成这一步。
        4. 试听仿真。点“送入仿真”，选择 SAMPLER 轨，用白键试听。
        5. 写入实机。选择 WAV 后点“导入选段并写入设备”；已编辑好网页库时点“写入设备采样库”。完成设备读回校验后才会报告成功。写入会替换全部 8 槽，所有项目中的同号采样一起变化。
        6. 分别备份。保存项目 .fm1，并备份采样库 .fm1s；只备份项目不能保存音频。

        写入采样时设备暂停播放和录入。进度前段发送，后段从设备读回核对；保持连接直到显示读回一致。选择 SAMPLER 对应槽重新触发试听，808 是独立合成引擎，不会使用导入的音频。若中断导致采样未就绪，重新写入完整采样库即可恢复。项目槽独立保留。

        采样检查发现正在写入、读取或校验错误、回复不完整时，不会自动覆盖采样。请按提示检查连接；需要恢复时，在“项目与音色”中手动写入备份或内置采样库。

        08 · MIDI、蓝牙与时钟

        USB 与网页连接

        下载完整 HTML 后可离线试听和编辑；读写设备需要支持 Web MIDI 的电脑 Chrome／Edge 和 USB 数据线，并允许 MIDI／SysEx。不能连接时先关闭占用 MIDI 的其他网页或软件，再重新连接。默认输入通道：轨 1–7 使用通道 1–7，轨 8 使用通道 10；可在 TRACK ROLE 修改。

        仿真页的“连接 MIDI 输入”用于外部键盘演奏网页。项目库连接用于读写实机项目和音色。USB 音频的输入／输出选择在电脑系统或音乐软件中设置。

        机身 MIDI IN（UART）与 USB MIDI 开机即同时接收，无需单独开启，也不受蓝牙总开关影响。两者使用相同的输入通道设置：默认轨道 1–7 使用通道 1–7，轨道 8 使用通道 10，可在 TRACK ROLE 修改。请选择对应通道，并检查轨道角色、静音与音量。

        通道与接收规则

        所有通道消息都按发送端 CHAN 响应：CH1–7 对应轨道 1–7，CH10 对应轨道 8。音符、弯音、调制和控制器使用同一映射，与屏幕选中轨道无关；未分配的 CH8、CH9、CH11–16 忽略。更换音源不改变通道。MIDI IN、USB MIDI 与 BLE MIDI 使用相同规则。

        例如键盘设为 CH2：音符、Pitch Bend、CC1、CC7 只控制轨 2；轨 8 使用 CH10。

        接收消息作用与范围
        Note On / Off全部音源接收 Note On／Off 和力度；Note On 力度 0 等同 Note Off。808／SAMPLER 按鼓音符选择声部。
        Pitch BendFM、303、PSG、Pluck 支持 14 位弯音，中心 8192，范围 ±2 半音；作用于已发声及后续音符。808／SAMPLER 的音高使用各声部 TUNE。
        CC1 · Mod WheelFM：音高颤音，音色 PMS 为 0 时调制轮仍有基础响应；303：EnvMod；PSG、Pluck、808、SAMPLER：轨道 LFO 深度，未设置 LFO 时为音量起伏。
        CC7 / CC10 / CC11 / CC91全部音源：CC7 轨道音量；CC10 声像（0 左、64 中、127 右）；CC11 表情（0 静音、127 原音量）；CC91 混响发送。
        CC64 / Channel Pressure / CC2 / CC4FM、303、PSG、Pluck：CC64 延音，64–127 踩下，0–63 松开。FM 另接收通道触后用于颤音，以及 CC2／CC4 的振幅控制，效果取决于音色振幅敏感度。
        CC120 / CC121 / CC123CC120 停止该轨声音；CC123 释放该轨外部音符（延音踏板仍有效）；CC121 复位实时弯音、表情、声像、调制和踏板，不改音色参数。
        Program ChangeProgram Change 使用 FM1 音色：FM 0–127 对应独立库的 128 个位置；303 0／1 为锯齿／方波；PSG 0–3 为 YM／AY／NOISE／MIX。其他音源忽略。部分软件显示为 1 起始编号。
        Engine CC303 还接收 CC5 滑音时间、CC71 共振、CC74 截止、CC75 衰减；PSG 接收 CC74 噪声、CC72 释放；Pluck 接收 CC74 亮度、CC75 衰减、CC72 释放。

        CC7、CC91、音色切换与音色参数编辑可随项目保存。弯音、表情、声像及实时调制不写入项目；CC121 不撤销已编辑的 303 EnvMod。FM1 保留自己的音色体系，不提供 GM 128 音色表。

        同步与走带

        Clock、Start、Continue、Stop、歌曲位置和 MMC 不带 MIDI 通道，控制整机。选择 MIDI 时钟后，外部 Clock 按每四分音符 24 个脉冲同步；仅发送 Clock 不会自行播放。Start 从起点开始，Continue 从当前位置继续，Stop 停止播放并释放音序和琶音音符。

        歌曲位置 SPP（F2）在 MIDI 时钟模式下定位，每单位为一个十六分音符，各轨按自身循环长度取余；随后发送 Continue 与 Clock。Start 会重新回到起点。System Reset（FF）停止、回起点并释放全部音符。

        MMC 支持 Stop（01）、Play（02）、Deferred Play（03）、Record Strobe（06）、Record Exit（07）和 Pause（09）；接收设备 ID 00 或广播 7F。Play／Deferred Play 从当前位置继续，Record Strobe 开始录入并续播，Record Exit 只结束录入，Stop／Pause 同时结束录入。在 MIDI 时钟模式仍需外部 Clock。

        例：F0 7F 7F 06 01 F7 为 MMC Stop；F0 7F 7F 06 02 F7 为 MMC Play。数字均为十六进制。

        同时连接多台 MIDI 设备时只让一台发送时钟和走带，避免重复脉冲。MTC 时间码、MMC 时间码定位／快进／倒带、RPN／NRPN、复音触后、GM Reset、Bank Select、Active Sensing 超时监控及未列出的控制器目前不实现，收到后忽略。

        蓝牙设置

        长按 SEQ，SELECT 选 BLUETOOTH / CLOCK，SAVE 打开蓝牙／时钟页。K1 为蓝牙总开关，K2 为蓝牙音频，K3 只选 BLE MIDI 的 DEVICE／HOST 角色，K4 选择时钟。蓝牙打开时 MIDI 服务自动可用；出厂默认蓝牙和音频打开、DEVICE 角色、内部时钟。PRESETS 选择屏幕下方操作，SAVE 执行：主设置页可打开 HOST 设备列表或清除 MIDI 配对；列表中 SELECT 选设备，PRESETS 选连接、扫描、断开或返回设置。清除配对仍需再次 SAVE 确认，HOME 取消。SEQ、EDIT 等上排功能键仍可直接切页。

        网页可以预览设置页面；实际蓝牙扫描、配对和音频输入要在实机上操作。

        INT 与 MIDI 时钟

        INT：FM1 使用内部速度，K4 可设 30–300 BPM。MIDI：跟随外部 MIDI Clock，需外部发送 Start／Continue 才开始或继续。此时旋转速度不会改变外部速度。超过约两秒收不到时钟，屏幕显示 LOST；检查外部设备是否发送时钟，或切回 INT。

        09 · 更新固件

        点击“刷回原厂 V15”，连接设备、勾选备份确认，再点击“刷入原厂 V15”并确认。网页会安装内置 V15，随后恢复四个库的 128 个出厂音色；已有音色会被覆盖。已是 V15 的设备会显示“恢复原厂音色”，无需重复刷固件。恢复中断时，重新连接并重试；完成后切换音色试听。Open 项目与采样不能用于原厂固件，原厂也不提供 Open 的构建哈希读回或项目库功能。回到 Open 时，点击“切回官方 Open 固件”并按强制烧录流程操作。不支持外部固件文件。

        1. 在“项目与音色”备份当前项目与采样库，其他需要保留的项目槽也逐一载入并备份。独立音色库 A–D 四组分别“读取此组”并“导出此组 .syx”；PLAY 轨的音色修改另行导出，DX7 也可存入独立库后再备份。
        2. 打开最新版工作台的“设备更新”，通过 USB 数据线连接 FM1。固件已内置。
        3. 勾选“已保存需要保留的音色、工程和采样”，点击“连接设备”，允许 MIDI／SysEx。
        4. 核对设备提示，点击“开始更新”，保持供电和 USB 连接直到完成。
        5. 等待重启及版本核对。如果提示采样未就绪，在采样页写入对应的 .fm1s 备份。写入内置采样库会替换全部 8 槽，不能找回原来的自定义采样。

        正常完成的同布局更新会保留有效项目槽和采样库；刷写前仍请分别备份工程、音色和采样。设备重启后，未保存的内存编辑不会自动恢复。固件更新也不会自动把网页仿真中的项目传到设备。

        若更新中断或设备停在升级界面，保留同一版本的这张网页，检查连接后重新连接并按提示继续。从其他固件迁移时，开启“强制烧录”，重新连接并确认兼容风险。固件不支持 USB-MIDI 升级协议时，请使用该版本配套的恢复工具。跨固件迁移可能清除项目和采样，务必先备份。

        正常连接已识别其他固件（例如 FM-1_015）时，点击 启用强制烧录并重新连接。这一步只开启模式并重新连接，不会写入固件。页面会说明接下来缺少哪一步；确认已备份后，再点 强制烧录 并确认兼容风险才会开始。也可点击强制烧录勾选行的任意位置开启。设备仍需支持兼容的 USB-MIDI 升级协议。

        拔插 USB 后重新点击连接即可；页面会清除旧设备信息。烧录与项目库切换时按提示重新连接。固件写入后请等待采样检查完成；“固件已更新”但采样未就绪时，只需检查或恢复采样库，无需重复烧录。

        连接失败时，展开“连接详情”查看本次浏览器检测到的 MIDI IN／OUT。未发现端口、端口无法配对、设备未回复型号是不同的问题。先关闭其他 MIDI 软件和更新网页，再重新开机、插拔 USB 并连接；强制烧录不能跳过设备握手。

        10 · 常见问题

        没有声音，或 MASTER 看起来没有变化

        网页检查静音按钮、输出电平和系统音量。实机检查 MASTER、轨道 LEVEL、静音／独奏和输出连接；MASTER 最小位置静音。

        PLAY 按了不走

        按 SEQ，转 ALGORITHM 到 SYNC / LOOP，检查 K1 的 INT／MIDI 时钟来源；没有外部时钟时切回 INT。若播放走动但没声音，确认当前轨已写入步进、未静音且音量不为零。

        旋钮功能与预期不同

        先看当前页面和屏幕底部名称。PRESETS 在总览切整套预设，在 EDIT 选单轨音色或鼓声部，在 SEQ 选步；K1–K4 随底部参数页改变。

        改好后重启丢了，或网页与实机不一致

        工作区编辑需要保存到 USER 槽。网页面板 SAVE 只保存浏览器本地内容；顶部“保存到设备”完成后，设备槽位才有该项目。自定义采样另外写入采样库并备份 .fm1s。

        换采样后其他项目的鼓声也变了

        所有项目共用 8 个采样槽。恢复对应的 .fm1s 库可找回原音频；导入 .fm1 项目不会恢复采样。

        挂音、组合键没松开

        实机按 HOME＋PLAY。网页按 Esc 或“紧急停音”，并取消锁定按钮。停止演奏后再关闭其他 MIDI 输入来源。

        网页无法连接或按钮不可用

        已识别设备时，切换强制烧录会自动重新连接，不会自动写入。等待连接完成，勾选备份确认，再点击强制烧录并确认兼容警告。尚未连接时，请先点击连接设备。

        用电脑 Chrome／Edge 打开网页链接或完整 HTML，避免使用不运行脚本的附件预览。检查 MIDI／SysEx 权限、USB 数据线和设备连接；关闭占用端口的软件。若浏览器提示安全上下文问题，请从 localhost 或 HTTPS 打开页面。

        首次用播放按钮、面板 PLAY 或空格播放时，会先开启声音。开启失败会保持停止，处理浏览器声音提示后可再次播放。声音开启过程中点“紧急停音”或切换面板页，会取消等待中的播放。

        Tap Tempo：在 FX 的 DELAY 页直接连按 SEQ，其他页面按住 HOME 连按 SEQ，或点击网页 TAP；连续两拍起生效，最多平均四个间隔，范围 30–300 BPM。FX 用 PRESETS 翻到 DELAY：K1 开关 SYNC，K2 调分频或毫秒，K3 调内部 BPM，K4 调反馈。新建工程默认同步八分音符；关闭 SYNC 后为固定时间 FREE，约 30–2040 毫秒。切换模式选择最接近的时间。T 为三连音，D 为附点；同步延迟跟随内部或外部 MIDI BPM，时钟丢失时保持最后间隔。旧工程保留原来的手动延迟；使用同步分频或扩展固定时间的工程需要新版固件。

/*
 * This is an implementation of wcwidth() (defined in
 * IEEE Std 1002.1-2001) for Unicode.
 *
 * http://www.opengroup.org/onlinepubs/007904975/functions/wcwidth.html
 *
 * In fixed-width output devices, Latin characters all occupy a single
 * "cell" position of equal width, whereas ideographic CJK characters
 * occupy two such cells. Interoperability between terminal-line
 * applications and (teletype-style) character terminals using the
 * UTF-8 encoding requires agreement on which character should advance
 * the cursor by how many cell positions. No established formal
 * standards exist at present on which Unicode character shall occupy
 * how many cell positions on character terminals. These routines are
 * a first attempt of defining such behavior based on simple rules
 * applied to data provided by the Unicode Consortium.
 *
 * For some graphical characters, the Unicode standard explicitly
 * defines a character-cell width via the definition of the East Asian
 * FullWidth (F), Wide (W), Half-width (H), and Narrow (Na) classes.
 * In all these cases, there is no ambiguity about which width a
 * terminal shall use. For characters in the East Asian Ambiguous (A)
 * class, the width choice depends purely on a preference of backward
 * compatibility with either historic CJK or Western practice.
 * Choosing single-width for these characters is easy to justify as
 * the appropriate long-term solution, as the CJK practice of
 * displaying these characters as double-width comes from historic
 * implementation simplicity (8-bit encoded characters were displayed
 * single-width and 16-bit ones double-width, even for Greek,
 * Cyrillic, etc.) and not any typographic considerations.
 *
 * Much less clear is the choice of width for the Not East Asian
 * (Neutral) class. Existing practice does not dictate a width for any
 * of these characters. It would nevertheless make sense
 * typographically to allocate two character cells to characters such
 * as for instance EM SPACE or VOLUME INTEGRAL, which cannot be
 * represented adequately with a single-width glyph. The following
 * routines at present merely assign a single-cell width to all
 * neutral characters, in the interest of simplicity. This is not
 * entirely satisfactory and should be reconsidered before
 * establishing a formal standard in this area. At the moment, the
 * decision which Not East Asian (Neutral) characters should be
 * represented by double-width glyphs cannot yet be answered by
 * applying a simple rule from the Unicode database content. Setting
 * up a proper standard for the behavior of UTF-8 character terminals
 * will require a careful analysis not only of each Unicode character,
 * but also of each presentation form, something the author of these
 * routines has avoided to do so far.
 *
 * http://www.unicode.org/unicode/reports/tr11/
 *
 * Markus Kuhn -- 2007-05-26 (Unicode 5.0)
 *
 * Permission to use, copy, modify, and distribute this software
 * for any purpose and without fee is hereby granted. The author
 * disclaims all warranties with regard to this software.
 *
 * Latest version: http://www.cl.cam.ac.uk/~mgk25/ucs/wcwidth.c
 */
