Install on your FM-1 ·

  1. Use Chrome or Edge on a computer (not Safari).
  2. Connect the FM-1 with a USB data cable, straight into the computer, and switch it on.
  3. Press Install. When the browser asks to allow MIDI, allow it.

Back up first: export your projects, DX7 voices and samples in the M-VAVE workbench (opens in a new tab). Do not unplug the USB cable while it writes.

Back to the original firmware

Puts M-VAVE's original FM-1 V15 back on, over the same cable. What FM-PLAITS saved may be lost.

If it gets stuck

If writing stops, the FM-1 stays in update mode: replug the USB cable and press Install again, and it carries on. Close other apps that use MIDI (DAWs, other update pages) before you start. M-VAVE's own updater, M-UPGRADE (m-vave.com/download (opens in a new tab)), also installs the files from this page.
