# FM-PLAITS

A generative Plaits voice for the M-VAVE FM-1, by [@narti_live](https://instagram.com/narti_live).

**Website, browser version and installer:** https://netroxic.github.io/fm1-fm-plaits/

- [Manual](MANUAL.md)
- Source: `FM1_FM_PLAITS_v1_source.zip` (M-VAVE FM1 Open V14 + FM-PLAITS, GPL-3.0 with the FM1 SDK linking exception)
- Every push builds the firmware on GitHub Actions (`.github/workflows/build.yml`) and publishes the site in `site/` with the new installer.
